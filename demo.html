Compare a menthol spectrum.

This example illustrates the outcome of comparing a hypothetical observed VCD spectrum with a calculated menthol spectrum.

  1. Download the sample files.
    Observed spectrum · Calculated spectrum
  2. Check the format.
    Each non-comment row has two tab-delimited numbers: frequency and VCD strength.
  3. Run the calculation.
    Use the calculator to obtain the superimposed spectra and SV score.
Example interpretation: an absolute SV value of 0.35 is greater than 0.20 and would support a high-confidence menthol assignment in this illustrative case. Interpret any result in the context of the complete experiment.
